# Programacao Orientada a Objetos em C#

Projeto de estudo inicial em C# com Windows Forms para praticar conceitos basicos de Programacao Orientada a Objetos.

## Objetivo do projeto

Exercitar a criacao de classes, objetos, propriedades, metodos e heranca em C#, usando exemplos simples com `Pessoa` e `Usuario`.

## Tecnologias utilizadas

- C#
- .NET Framework
- Windows Forms
- Visual Studio

## Funcionalidades

- Instanciacao de objetos da classe `Pessoa`
- Atribuicao de propriedades como nome, CPF e data de nascimento
- Exibicao de dados por `MessageBox`
- Exemplo de heranca com a classe `Usuario`
- Entrada de dados pela interface Windows Forms

## Estrutura do projeto

```text
programacao-orientada-a-objetos-csharp/
`-- TestePOO/
    |-- Pessoa.cs
    |-- Usuario.cs
    |-- Form1.cs
    |-- Form2.cs
    |-- Program.cs
    |-- TestePOO.csproj
    `-- TestePOO.sln
```

## Como executar

1. Clone o repositorio:

```bash
git clone https://github.com/murilotpiai/programacao-orientada-a-objetos-csharp.git
```

2. Abra `TestePOO/TestePOO.sln` no Visual Studio.
3. Compile e execute o projeto.
